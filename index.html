2. 부품 및 배선

버튼은 INPUT_PULLUP 방식이라 버튼의 한쪽을 D2, 다른 쪽을 GND에 연결합니다.

부품아두이노 핀연결 메모
빨간 LEDD8LED 긴 다리(+)는 저항을 거쳐 D8, 짧은 다리(-)는 GND
노란 LEDD9LED 긴 다리(+)는 저항을 거쳐 D9, 짧은 다리(-)는 GND
초록 LEDD10LED 긴 다리(+)는 저항을 거쳐 D10, 짧은 다리(-)는 GND
버튼D2 + GND외부 풀업 저항 없이 INPUT_PULLUP 사용
부저D5 + GND부저 (+)를 D5, (-)를 GND

주의: LED마다 보통 220Ω~330Ω 저항을 직렬로 연결하세요. 부저 종류에 따라 소리 크기와 재생 결과가 달라질 수 있습니다.

음표 재생시간 합계는 약 4.5초이며, 각 음 사이에 30ms 간격이 추가됩니다.

버튼 디바운스는 50ms입니다. 노란불은 멜로디 재생이 끝날 때까지 켜져 있습니다. 별도의 고정 3초 타이머가 적용되는 코드는 아닙니다.

4. 전체 Arduino 코드

Arduino IDE에 복사해 업로드할 수 있는 전체 스케치입니다.

const int RED = 8;
const int YELLOW = 9;
const int GREEN = 10;
const int BUTTON = 2;
const int BUZZER = 5;

bool greenMode = false;
bool lastReading = HIGH;
bool stableButton = HIGH;

unsigned long debounceTime = 0;

void setLights(bool red, bool yellow, bool green) {
  digitalWrite(RED, red);
  digitalWrite(YELLOW, yellow);
  digitalWrite(GREEN, green);
}

// 반복적이고 강한 힙합 느낌의 오리지널 멜로디
void playMelody() {
  int melody[] = {
    587, 587, 784, 659,
    587, 587, 784, 659,
    523, 587, 659, 784,
    659, 587, 523, 587,
    587, 784, 659, 587
  };

  int durations[] = {
    180, 180, 180, 300,
    180, 180, 180, 300,
    180, 180, 180, 300,
    180, 180, 180, 300,
    180, 180, 180, 400
  };

  for (int i = 0; i < 20; i++) {
    tone(BUZZER, melody[i], durations[i]);
    delay(durations[i] + 30);
  }

  noTone(BUZZER);
}

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);

  pinMode(BUTTON, INPUT_PULLUP);
  pinMode(BUZZER, OUTPUT);

  // 처음에는 빨간불
  setLights(HIGH, LOW, LOW);
}

void loop() {
  bool reading = digitalRead(BUTTON);

  // 버튼 채터링 방지
  if (reading != lastReading) {
    debounceTime = millis();
  }

  if (millis() - debounceTime > 50) {
    if (reading != stableButton) {
      stableButton = reading;

      // 버튼을 누르면 노란불 + 멜로디
      if (stableButton == LOW) {
        setLights(LOW, HIGH, LOW);

        playMelody();

        // 멜로디가 끝나면 신호 변경
        greenMode = !greenMode;

        if (greenMode) {
          setLights(LOW, LOW, HIGH);
        } else {
          setLights(HIGH, LOW, LOW);
        }
      }
    }
  }

  lastReading = reading;
}
